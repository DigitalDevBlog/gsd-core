<objective>
## Goal
Stand up a running MkDocs Material site with a navigation skeleton covering all eight
documentation areas, buildable with `mkdocs build --strict` (exit 0, no warnings) and
viewable with `mkdocs serve`.

## Purpose
Nothing else in "Understanding GSD Core" can ship without a running site. This plan
delivers the foundation the seven content phases publish into.

## Output
- `mkdocs.yml` (Material theme, relocated docs_dir, nav skeleton)
- `requirements.txt` (pinned docs tooling)
- `learn/` tree: landing page + one placeholder page per section
- `.gitignore` updated to ignore build output
- A locally serveable site
</objective>

<context>
## Project Context
@.paul/PROJECT.md
@.paul/ROADMAP.md
@.paul/STATE.md

## Environment (verified during planning)
- python3 3.14.6 + pip3 available (/opt/homebrew/bin)
- `mkdocs.yml`, `requirements.txt`, `learn/`, `learn-site/` are all free at repo root
- **`docs/` is NOT free** — the repo's own documentation tree holds 406 tracked files.
  MkDocs' default `docs_dir` must be relocated to `learn/`.
- `.venv/` is already gitignored (.gitignore line 297); `learn-site/` is not
- Repo is a Node package (@opengsd/gsd-core v1.11.0); docs tooling must stay
  self-contained and must not touch src/, skills/, agents/, hooks/, or package.json
</context>

      - docs_dir: learn        # REQUIRED: docs/ is the repo's own tree, 406 tracked files

        toc (permalink: true)
      - nav: Home plus the eight content sections in roadmap order

    --strict. Do not add the kroki or mike plugins in this plan.
