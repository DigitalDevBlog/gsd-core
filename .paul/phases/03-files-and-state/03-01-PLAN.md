<objective>
## Goal
Document the artifact set GSD Core uses to carry state between loop stages — what each
template is for, when it is created, who reads it, and the design rules that keep the set
coherent.

## Purpose
State design is where most homegrown agent frameworks fail: they either keep nothing
between stages or keep everything. GSD Core's 46 templates encode a specific answer, and
that answer is directly transferable.

## Output
- `learn/files/index.md` — the artifact set and its lifecycle
